# Math Agent CLI

Локальное приложение на Python для решения школьных математических задач и подготовки результатов в Excel и GeoGebra.

Учебный проект с фокусом на задачи 9-11 классов, включая норвежскую программу 2P / 2P-Y. Основной интерфейс - командная строка: пользователь вводит условие, приложение определяет тип задачи, извлекает параметры и выбирает математический решатель.

**Статус:** дальнейшая разработка прекращена. Эта страница сохраняет описание проекта для портфолио; исходный код приложения в этот репозиторий не включён.

## Задача проекта

Объединить в одном инструменте решение типовых школьных задач, краткий текстовый ответ и создание файлов для дальнейшей работы. Основные вычисления выполняются локально; интеграция с Ollama предусмотрена как дополнительная возможность.

## Возможности

| Направление | Реализованные сценарии, описанные в документации проекта |
| --- | --- |
| Алгебра | Линейные и квадратные уравнения, простые неравенства, системы уравнений |
| Функции | Линейные, квадратные и экспоненциальные функции, графики и таблицы значений |
| Проценты | Скидки, рост и спад, обратный расчёт исходной величины |
| Финансовые задачи | Процентные ставки, кредитные платежи, планы погашения, сравнение типов кредита |
| Статистика | Среднее, медиана, мода, разброс, частотные и интервальные таблицы |
| Геометрия | Площади, теорема Пифагора, подобие треугольников и масштаб |
| Excel | Создание `.xlsx` для поддерживаемых задач с формулами в вычисляемых ячейках |
| GeoGebra | Подготовка команд для поддерживаемых задач по явному запросу пользователя |

Ввод ориентирован на русский язык с поддержкой норвежских и распространённых английских математических терминов. Поддержка языков зависит от типа задачи и формулировки.

## Архитектура

Обработка разделена на несколько этапов:

```text
Текст условия
  -> Нормализация и классификация
  -> Извлечение параметров
  -> Маршрутизация к решателю
  -> Математическое вычисление
  -> Проверка и форматирование
  -> Текстовый ответ / Excel / команды GeoGebra
```

Ключевые части исходного приложения:

- `main.py` и `app/cli.py`: точка входа и команды CLI.
- `app/router.py`: маршрутизация задач.
- `app/services/`: обработка текста, извлечение параметров, проверка и объяснения.
- `app/solvers/`: математические решатели.
- `app/intents/`: определение запроса на дополнительные файлы.
- `app/artifacts/`: создание выходных файлов.
- `tests/` и `tests/fixtures/`: автоматические проверки и наборы школьных задач.

Решение задачи и создание файла разделены: запрос Excel или GeoGebra обрабатывается отдельно от выбора математического метода.

## Технологии

**Python**, **Typer / Click**, **SymPy**, **NumPy**, **SciPy**, **pandas**, **openpyxl**, **Matplotlib**, **Pydantic**, **Rich**. Дополнительная интеграция: **Ollama**. Проверки: **pytest** и собственный инструмент оценки школьных задач.

## Пример сценария

В исходном приложении пользователь мог передать уравнение основной команде:

```bash
python main.py solve "x^2 - 5x + 6 = 0"
```

Математический результат для этого примера: `x = 2` и `x = 3`.

Для поддерживаемой финансовой задачи пользователь мог дополнительно запросить таблицу Excel. Приложение подготавливало файл в `outputs/`, сохраняя вычисляемые значения как формулы. Например, в локальной версии создавался файл `finance_monthly_table.xlsx`.

## Инженерные решения

- Детерминированные решатели для поддерживаемых математических классов задач.
- Разделение CLI, обработки условий, вычислений и экспорта.
- Формулы в Excel вместо подстановки заранее вычисленных значений.
- Отдельные проверки парсеров, решателей, CLI и структуры Excel-файлов.
- Наборы школьных задач для выявления регрессий при изменении обработки условий.
- Сообщения о недостаточных данных и неподдерживаемом вводе.

## Ограничения

Проект не является универсальным решателем произвольных задач. Результат зависит от распознавания формулировки и наличия подходящего решателя. Часть сценариев накоплений, свободных текстовых условий и экспорта поддерживалась частично. Числовые данные, присутствующие только на рисунке или в изображении PDF, нужно было вводить вручную.

## Краткое описание для резюме

**Math Agent CLI | Python, SymPy, pandas, openpyxl, Matplotlib.** Учебный проект локального CLI для школьных математических задач: обработка условий, выбор специализированных решателей, финансовые и статистические расчёты, подготовка Excel-файлов с формулами и команд GeoGebra. Архитектура разделяет обработку текста, вычисления и экспорт; для проверки предусмотрены автоматические тесты и наборы школьных задач.
